# 华复保利企业工作台2.0 — 系统界面字段说明与后端对接规范

> **文档用途**：本文档对系统中每个页面的所有数据字段进行逐一说明，包括字段名（中文+英文）、数据类型、描述、必填/选填、数据来源、示例值，方便后端开发团队进行API对接。
>
> **设计风格**：Bento Box（大圆角、轻柔阴影、白底#F5F5F7、胶囊按钮、彩色渐变卡片）
>
> **生成日期**：2026-07-25

---

## 一、通用字段规范

以下字段在多个页面中反复使用，统一在此定义。

| 字段名（中文） | 字段名（英文） | 类型 | 说明 |
|---|---|---|---|
| 编号/编码 | `code` / `id` | string | 系统自动生成，格式：模块前缀-年月序号，如 `EMP-001`、`HT-2026-001` |
| 状态 | `status` | enum | 各模块有独立状态枚举，详见各页面 |
| 创建时间 | `createdAt` | datetime | ISO 8601格式，如 `2026-07-24T10:52:00+08:00` |
| 更新时间 | `updatedAt` | datetime | ISO 8601格式 |
| 创建人 | `createdBy` | string | 员工编号 |
| 更新人 | `updatedBy` | string | 员工编号 |
| 备注 | `remark` | string | 选填，最大500字 |
| 操作人 | `operatorName` | string | 当前登录用户的姓名 |
| 操作人头像 | `operatorAvatar` | string | 头像URL或渐变色配置 |

| 岗位管理 | `/api/hr/position` | 岗位编制、职级体系 |
| 考勤管理 | `/api/hr/attendance` | 考勤汇总、日历、请假 |
| 绩效管理 | `/api/hr/performance` | 考核方案、评估记录 |

| 培训管理 | `/api/hr/training` | 培训项目、技能树 |
| 劳动合同 | `/api/hr/labor-contract` | 劳动合同台账、续签 |
| 数据报表 | `/api/hr/report` | 统计图表、成本预警 |
| 合同管理 | `/api/contract/main` | 合同台账、关系树 |
| 相对方 | `/api/contract/counterparty` | 客商台账、准入 |
